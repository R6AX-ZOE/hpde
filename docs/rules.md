# 哈利波特·决斗时代

## 决斗规则

生命值：3000

普攻：30  
普攻范围：50   
普攻速度：1/s

胜利条件：某一方生命值全员归零（1v1/2v2/3v3/4v4）

场地大小：1280*720

移动：每人20张移动卡。使用一张移动卡，以 140/s 的速度移动到指定位置（不能越过中线），在 1.5 秒内更换移动位置不额外消耗移动卡。当移动卡数量归零后，每6秒恢复一张移动卡。

魔力：上限10，初始5，每秒回复1.2点（120s前） / 1.5点（120s后）

魔法卡：8张循环，手牌恒为4张，另有4张卡构成一个序列。打出一张手牌后，该卡移至序列末尾，从序列头部即时补入一张新手牌。魔法卡会消耗魔力。

伙伴卡：3张，按构筑顺序使用，不消耗魔力。    
cd：5s, 60s, 60s

魔药：2种，各自独立冷却，每种一局最多使用10次，不消耗魔力。

拉起：多人模式下，每人死亡后可被拉起至多两次，起身血量为第一次1000/第二次600。

## BP

在决斗开始前，每人有 10s 时间，每人预选一个回响，每方不能包含重复回响，预选回响对对手不可见；

然后每方每人在 20s 内禁用一个回响，不限顺序，同一方不能多次禁用同一回响，禁用回响时，对方禁用回响的内容不可见，结束后公示回响禁用情况 5s ；

双方逐人选定回响，每人最多使用 5s 选定一个回响，不能选择重复回响；

最后 50s 内每人调整自己的卡组，准备开始决斗。
